SolidCraft

An open-source parametric 3D CAD application written in Rust. Sketch, constrain and build solid parts on the desktop or in the browser, and automate it through its MCP server.

Website GitHub Dashboard

CamCraft

An open-source, clean-room CAM package written in Rust. It turns 3D models into checked G-code for CNC mills, lathes, plasma and wire EDM, and refuses a toolpath it cannot prove safe.
